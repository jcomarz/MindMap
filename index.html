Google Sheets

  1. Open the spreadsheet you want this map to live in.
  2. Fill in the Token box below first, then copy the bridge script — it is copied with that token already in it.
  3. Extensions → Apps Script. Delete what is there, paste the script, save.
  4. Deploy → New deployment → Web app. Run as yourself, access: anyone with the link.
  5. Copy the /exec URL it gives you into the first box below, then Done.
  6. Changed the script later? Deploy → Manage deployments → edit → Version: New version. Editing alone does not update the live URL.

Sheets are saved with the map and written to the Sync tab of your workbook. Use Copy a link to this setup to carry the same connection to another device.
